# Contributing

This is an academic group project repository. Before proposing changes:

1. Keep the submitted source available when making substantial firmware revisions.
2. Document hardware pin changes in the README and project documentation.
3. Record the exact board, library versions, and test setup used for validation.
4. Do not describe proposed cloud or mobile features as implemented until they are built and tested.
5. Do not commit credentials, private keys, or personal student identifiers.
